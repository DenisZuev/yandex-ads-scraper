# Yandex Ads Scraper

Chrome-расширение (Manifest V3) для сбора рекламных объявлений со страниц поиска Яндекса.

## Возможности

- Сбор обычных объявлений и медийной рекламы (баннеры)
- Ручной сбор с текущей страницы
- Пакетный сбор по списку запросов (до 50, параллельно по 3)
- Извлечение реальных URL рекламодателей (с UTM-параметрами) без кликов по рекламе
- Экспорт в JSON, CSV и копирование ссылок в буфер
- Side panel — интерфейс в боковой панели браузера
- Дедупликация сессий при повторном сборе
- Полностью локальная обработка (данные не покидают браузер)

## Установка

1. Скачайте или клонируйте репозиторий
2. Откройте Chrome → `chrome://extensions/`
3. Включите «Режим разработчика»
4. «Загрузить распакованное расширение» → выберите папку `yandex-ads-scraper`

## Использование

### Ручной сбор
1. Откройте поиск Яндекса (`ya.ru/search/?text=...`)
2. Нажмите на иконку расширения → откроется боковая панель
3. Вкладка **Вручную** → «Собрать рекламу»
4. Результаты появятся в списке сессий

### Пакетный сбор
1. Вкладка **Пакетный**
2. Введите запросы (каждый с новой строки или через запятую)
3. «Старт» — расширение по очереди ищет каждый запрос и собирает рекламу
4. «Стоп» — остановить досрочно

### Работа с данными

Каждая сессия:
| Кнопка | Действие |
|--------|----------|
| 📋 | Скопировать все URL сессии в буфер |
| JSON | Скачать сессию как JSON |
| CSV | Скачать сессию как CSV |
| ✕ | Удалить сессию |

Тулбар (все сессии):
| Кнопка | Действие |
|--------|----------|
| 📋 URL | Скопировать все URL из всех сессий |
| ↓ JSON | Скачать все сессии как JSON |
| ↓ CSV | Скачать все сессии как CSV |
| ✕ Очистить | Удалить все сессии |

## Формат данных

```json
{
  "metadata": {
    "collectionTimestamp": "2026-05-18T09:53:01.000Z",
    "pageUrl": "https://ya.ru/search/?text=пластиковые+окна+спб",
    "searchQuery": "пластиковые окна спб",
    "adCount": 11
  },
  "ads": [
    {
      "title": "Окна от производителя со скидкой 30%",
      "url": "https://okna-leningrad.ru/okna/?utm_source=yandex&utm_medium=cpc&utm_campaign=...&yclid=...",
      "description": "Качественные окна ПВХ. Бесплатный замер и монтаж. Рассрочка 0%.",
      "position": 1,
      "additionalLinks": ["Бесплатный замер", "Рассрочка", "Гарантия"],
      "utmParams": {
        "utm_source": "yandex",
        "utm_medium": "cpc",
        "utm_campaign": "...",
        "utm_content": "...",
        "utm_term": "..."
      }
    }
  ]
}
```

### UTM-параметры

Извлекаются из URL объявления:
- `utm_source` — источник трафика (yandex)
- `utm_medium` — тип канала (cpc)
- `utm_campaign` — ID рекламной кампании
- `utm_content` — ID объявления
- `utm_term` — ключевое слово

## Как это работает

### Поиск рекламы
Обычные объявления — по классу `.Organic_withAdvLabel` (и его обфусцированным вариантам). Медийная реклама — по классу `.AdvMedia-Item`.

### Извлечение URL
Реальный URL рекламодателя лежит в атрибуте `data-vnl` кнопки Extralinks:
`data-vnl` → `items[]` → `reportFeedback.customMetaFields[].snippetUrl`

Никаких запросов к `yabs.yandex.ru` — URL читается прямо из DOM.

### Кириллические домены
Punycode-домены вида `xn----7sbebp4a0bp.xn--p1acf` декодируются в `века-спб.рус` для отображения.

```bash

```

## Обновление селекторов

Если Яндекс изменит структуру страницы:
1. Откройте `content.js` → `this.selectors`
2. Обновите CSS-селекторы
3. Перезагрузите расширение в `chrome://extensions/`

## Известные ограничения

- Парсинг карточек Яндекс.Бизнес временно отключён
- Сбор только с текущей страницы (без пагинации)
- Пакетный режим работает только на `ya.ru`
