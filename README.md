# Yandex Ads Scraper

Chrome расширение для сбора рекламных объявлений со страниц поиска Яндекса.

## Возможности

- ✅ Сбор всех рекламных объявлений с текущей страницы поиска
- ✅ Автоматическая классификация по типу размещения (спецразмещение/гарантия)
- ✅ Извлечение полных URL с UTM-параметрами для анализа кампаний
- ✅ Извлечение заголовка, описания и дополнительных ссылок (уточнений)
- ✅ Визуальная подсветка собранных объявлений на странице (цветовая кодировка)
- ✅ Предпросмотр найденных объявлений перед сохранением
- ✅ Экспорт данных в JSON формат
- ✅ Работает на ya.ru и yandex.ru
- ✅ Полностью локальная обработка данных (без отправки на сервер)
- ✅ Простой интерфейс на русском языке

## Установка

### Вариант 1: Режим разработчика (для тестирования)

1. Скачайте или клонируйте этот репозиторий
2. Откройте Chrome и перейдите на `chrome://extensions/`
3. Включите "Режим разработчика" (Developer mode) в правом верхнем углу
4. Нажмите "Загрузить распакованное расширение" (Load unpacked)
5. Выберите папку `yandex-ads-scraper`
6. Расширение установлено! Иконка появится на панели инструментов

### Вариант 2: Chrome Web Store (будет доступно после публикации)

Установите расширение из Chrome Web Store (ссылка будет добавлена после публикации).

## Использование

1. **Откройте страницу поиска Яндекса**
   - Перейдите на https://ya.ru или https://yandex.ru
   - Введите поисковый запрос (например, "натяжной потолок москва")

2. **Запустите сбор рекламы**
   - Нажмите на иконку расширения в панели инструментов Chrome
   - Нажмите кнопку "Собрать рекламу"
   - Дождитесь завершения сбора (обычно 1-2 секунды)

3. **Просмотрите результаты**
   - Собранные объявления будут подсвечены на странице:
     - 🟢 **Зеленый** - Спецразмещение (над первым органическим результатом)
     - 🔵 **Синий** - Гарантия (под первым органическим результатом)
     - 🟠 **Оранжевый** - Яндекс.Бизнес (временно отключено)
   - В popup отобразится список найденных объявлений с предпросмотром

4. **Сохраните данные**
   - Нажмите кнопку "Скачать JSON"
   - JSON файл автоматически скачается в папку загрузок
   - Имя файла: `yandex-ads-YYYY-MM-DDTHH-MM-SS.json`
   - Подсветка автоматически исчезнет после скачивания

## Формат данных

Экспортируемый JSON файл содержит:

```json
{
  "metadata": {
    "collectionTimestamp": "2026-05-05T11:39:39.298Z",
    "pageUrl": "https://ya.ru/search/?text=натяжной+потолок+москва",
    "searchQuery": "натяжной потолок москва",
    "adCount": 11,
    "userAgent": "Mozilla/5.0..."
  },
  "ads": [
    {
      "title": "Натяжные потолки в Москве. Рассчитайте цену на сайте",
      "url": "https://mos.prestigepotolok.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign=707348178&utm_content=17608791693&utm_term=натяжные%20потолки%20москва&yclid=10363417335924260863",
      "description": "От 385 р/м2. Светильники, карнизы в подарок. Успейте получить до конца акции!",
      "position": 0,
      "adType": "спецразмещение",
      "additionalLinks": [
        "Бесплатный замер",
        "Рассрочка 0%",
        "Гарантия 15 лет"
      ],
      "rawAttributes": {
        "cid": null,
        "fastName": null
      }
    }
  ]
}
```

### Поля данных

- **title** - заголовок объявления
- **url** - полный URL посадочной страницы с UTM-параметрами
- **description** - текст описания объявления
- **position** - порядковый номер на странице (0-based)
- **adType** - тип размещения:
  - `спецразмещение` - объявления над первым органическим результатом
  - `гарантия` - объявления под первым органическим результатом
  - `яндекс.бизнес` - карточки организаций (временно отключено)
- **additionalLinks** - массив текстов уточнений/быстрых ссылок (без URL)
- **rawAttributes** - технические атрибуты (cid, fastName)

### Анализ UTM-параметров

URL содержат полные UTM-метки, которые позволяют анализировать:

**utm_source** - источник трафика
- `yandex` - Яндекс.Директ

**utm_medium** - тип канала
- `cpc` - контекстная реклама (cost per click)

**utm_campaign** - ID рекламной кампании
- `707348178` - идентификатор кампании конкурента

**utm_content** - ID объявления
- `17608791693` - конкретное объявление для A/B тестирования

**utm_term** - ключевое слово
- `натяжные%20потолки%20москва` - поисковый запрос

**yclid** - Yandex Click ID
- Уникальный идентификатор клика для отслеживания конверсий

**Применение:**
- Конкурентный анализ рекламных стратегий
- Определение ключевых слов конкурентов
- Анализ структуры кампаний
- Отслеживание изменений во времени

## Технические детали

### Архитектура

- **Manifest V3** - современный стандарт Chrome расширений
- **Content Script** - внедряется на страницы ya.ru/search и yandex.ru/search
- **Popup UI** - интерфейс для запуска сбора данных и предпросмотра
- **Background Service Worker** - обработка событий жизненного цикла

### Идентификация рекламы

Расширение определяет рекламные блоки по классу `.Organic_withAdvLabel` - это четкий маркер рекламы в выдаче Яндекса.

### Классификация по типу размещения

Алгоритм определения типа:

1. Находит первый органический результат (`.Organic:not(.Organic_withAdvLabel)`)
2. Сравнивает вертикальную позицию объявления с первым органическим результатом
3. Если объявление **выше** → `спецразмещение`
4. Если объявление **ниже** → `гарантия`

### Извлечение реальных URL

Расширение извлекает настоящие посадочные страницы из атрибута `data-vnl`:
- Парсит JSON из `data-vnl`
- Извлекает `noRedirectUrl` - прямой URL без редиректа через yabs.yandex.ru
- Сохраняет все UTM-параметры для анализа

### CSS селекторы

Парсер использует каскадную стратегию с запасными селекторами:

- **Контейнеры**: `.Organic_withAdvLabel`
- **Заголовки**: `.OrganicTitle-Link`, `.Organic-Title a`
- **Описания**: `.OrganicText`, `.Organic-Text`
- **Уточнения**: `.OrganicSitelinks`, `.Sitelinks`

### Визуальная подсветка

Собранные объявления подсвечиваются цветной рамкой:
- Зеленая (#4CAF50) - спецразмещение
- Синяя (#2196F3) - гарантия
- Оранжевая (#FF9800) - яндекс.бизнес (временно отключено)

Подсветка автоматически удаляется при скачивании или отмене.

## Требования

- Chrome 88 или новее
- Активное подключение к интернету (для загрузки страниц Яндекса)

## Приватность

- ✅ Все данные обрабатываются локально в браузере
- ✅ Никакие данные не отправляются на внешние серверы
- ✅ Нет постоянного хранения данных (кроме скачанных JSON файлов)
- ✅ Нет сбора личной информации пользователей

## Разрешения (Permissions)

Расширение запрашивает следующие разрешения:

- `activeTab` - доступ к активной вкладке при клике на иконку
- `downloads` - скачивание JSON файлов
- `scripting` - внедрение content script на страницы Яндекса
- `host_permissions` - доступ к ya.ru и yandex.ru

## Устранение неполадок

Для подробного руководства по устранению неполадок см. **[TROUBLESHOOTING.md](TROUBLESHOOTING.md)**

### Расширение не работает

1. Убедитесь, что вы находитесь на странице поиска Яндекса (ya.ru/search или yandex.ru/search)
2. Попробуйте перезагрузить страницу (F5)
3. Проверьте консоль браузера (F12) на наличие ошибок

### Не находит рекламу

1. Убедитесь, что на странице действительно есть реклама (метка "Промо")
2. Попробуйте другой поисковый запрос (коммерческие запросы обычно содержат больше рекламы)
3. Проверьте, что вы не используете блокировщик рекламы

### JSON файл не скачивается

1. Проверьте настройки браузера для скачивания файлов
2. Убедитесь, что у браузера есть разрешение на скачивание файлов
3. Попробуйте очистить кэш и перезапустить браузер

### Ошибка "Could not establish connection"

1. Перезагрузите страницу (F5)
2. Убедитесь, что вы на странице поиска Яндекса
3. Попробуйте переустановить расширение

## Разработка

### Локальная разработка

```bash
# Клонировать репозиторий
git clone <repository-url>
cd yandex-ads-scraper

# Загрузить расширение в Chrome
# 1. Откройте chrome://extensions/
# 2. Включите "Режим разработчика"
# 3. Нажмите "Загрузить распакованное расширение"
# 4. Выберите папку yandex-ads-scraper
```

### Тестирование

1. Откройте страницу поиска Яндекса
2. Откройте консоль разработчика (F12)
3. Нажмите на иконку расширения и "Собрать рекламу"
4. Проверьте логи в консоли:
   - `Yandex Ads Scraper content script loaded`
   - `Found X ad blocks`
   - `Successfully collected X ads`
   - `Highlighted X ad blocks`

### Отладка

- **Content Script**: Логи выводятся в консоль страницы (F12)
- **Popup**: Правый клик на иконку → "Проверить всплывающее окно"
- **Background**: chrome://extensions/ → "Проверить представления: service worker"

## Обновление селекторов

Если Яндекс изменит структуру страницы и расширение перестанет работать:

1. Откройте `content.js`
2. Найдите объект `this.selectors` в классе `YandexAdParser`
3. Обновите CSS селекторы на актуальные
4. Перезагрузите расширение в chrome://extensions/

## Известные ограничения

- ⚠️ Парсинг карточек Яндекс.Бизнес временно отключен (требует доработки)
- ⚠️ Собирает только объявления с текущей страницы (без пагинации)
- ⚠️ Не собирает графические объявления и баннеры
