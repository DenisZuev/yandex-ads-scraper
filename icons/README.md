# Icons

Для полноценной работы расширения необходимо создать PNG иконки из SVG шаблона:

## Требуемые размеры:
- icon16.png (16x16 пикселей)
- icon48.png (48x48 пикселей)  
- icon128.png (128x128 пикселей)

## Как создать:

### Вариант 1: Онлайн конвертер
1. Откройте https://cloudconvert.com/svg-to-png
2. Загрузите icon16.svg
3. Установите нужный размер (16x16, 48x48, 128x128)
4. Скачайте PNG файлы

### Вариант 2: ImageMagick (если установлен)
```bash
convert icon16.svg -resize 16x16 icon16.png
convert icon16.svg -resize 48x48 icon48.png
convert icon16.svg -resize 128x128 icon128.png
```

### Вариант 3: Временное решение
Для тестирования можно использовать любые PNG иконки нужных размеров.
Расширение будет работать с любыми иконками.
